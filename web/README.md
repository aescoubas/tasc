# Tasc Web Dashboard

This is the React-based web dashboard for Tasc.

## Prerequisites

1.  **Go Server**: You must have the `tasc` API server running.
    ```bash
    tasc serve
    ```
    (By default it listens on port 8081).

2.  **Node.js**: Ensure Node.js is installed.

## Setup

Install dependencies:
```bash
npm install
```

## Running

Start the development server:
```bash
npm run dev
```

Open your browser to the URL shown (usually http://localhost:5173).

## Building

To build for production:
```bash
npm run build
```
The artifacts will be in `dist/`.
